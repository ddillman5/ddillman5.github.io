Global Time App

This global time app allows users to view the local time of cities from around
the world.  Users can select from a variety of cities in a dropdown menu and
can 'pin' them to a dashboard on the webpage.  Users can then remove whichever
cities they desire, and can also change the webpage to dark mode if they'd like.

Features:
- Add cities to the dashboard
- Remove cities from the dashboard
- Select cities from a dropdown
- View the page in dark mode or light mode
